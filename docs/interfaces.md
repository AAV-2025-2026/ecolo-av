# Interfaces

Generated from `docs/interfaces.yaml` by `tools/gen_interfaces_md.py`; edit the YAML.
Check a running system against it with `pixi run check <turtle|sim|road|spine|car|replay|bench>`.
`road` is the sim in its road world (`world:=road`): what is live in `sim` must be live there too. `spine` is the road world with the spine in the loop (`spine:=true`): what is live in `road` must be live there too.
