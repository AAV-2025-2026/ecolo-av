# Car audit, 6 November 2026

The evening we tried to drive as is (`docs/car-evening.md`). Everything here only read: no
flashing, no service changed, no drive tool used. The car lost power once at about 17:38, then
again before the end. Full survey files are outside git, on Ben's Mac: `~/aav-audit/2026-11-06/`.

## The short version

| Question | Answer | How sure |

**What it was (Ben, later that evening):** "a hardware fuse and a questionalbe circuit board". With
those dealt with, the car moved forward. So the software path was never the fault. Still to write
down: which fuse, its rating, why it blew, and which board and what's wrong with it.

## The signal, link by link

```text
 Remote → receiver → ESP32 → DAC chip → voltage → motor controller → motor
   ✅        ✅        ✅        ✅          ❓            ❓            ❓
                         └──→ Jrks → steering and brake actuators
                               ❓            ❓

 Joystick → CORTEX /joy ✅ → /driveData ❌ (trigger not held) → ESP32 ❌ (on RC)
```

## What misled us

| Thing | What it really means |
|---|---|
| `STR:OK BRK:OK` | Set once at boot. It doesn't say the Jrks answer now |
| `steer=` in the log | The wish, not the wheel |
| The boot line `MID=Fwd` | The code makes the middle BRAKE: under 1200 forward, over 1800 reverse |
| `accel=-1.00` in forward | Left over from brake; forward doesn't clear it |
| The status page looks frozen | About 130 near-identical lines a second |
| Doctor's "the old car: 28 topics" | Mostly two copies of our own `drive_server` on this Mac, on domain 0 |
| Pushing the throttle stick up | Does nothing: only CH3 under about 1450 is throttle |
